15 Q&A Prep

Tough Questions, Confident Answers

What the Dean, Principal & faculty may ask — and the evidence-backed response.

? "What if the internet fails during a 1,000-person fest?"
A Offline PWA Protocol — scanner caches the full guest list in encrypted local storage, validates passes in under 0.5s, and auto-syncs when network returns.
? "Can a student create a fake or inappropriate event?"
A No — strict RBAC. Only verified club organizers can create events, and every event requires faculty/admin approval before it appears publicly.
? "How does this help NAAC / NBA accreditation?"
A AI report generator exports structured DOCX/PDF — participant lists, time-stamped attendance, feedback & financials — formatted for NAAC Criterion V.
? "Is student data secure and private?"
A JWT with refresh-token rotation, 2FA, encrypted password hashing, role-based queries & rate-limiting — blocking unauthorized access or scraping.
? "Will the server crash if 2,000 students register at once?"
A No — PDF tickets, certificates & bulk mail run on async BullMQ/Redis workers, keeping the main API server light and responsive.
